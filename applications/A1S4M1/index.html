Synthèse de Cours : Proportionnalité et Échelles de Plans

1. Définition d'une échelle

L'échelle $E$ d'un plan ou d'une carte est le coefficient de proportionnalité permettant de passer d'une dimension réelle à la dimension représentée sur le plan (exprimées obligatoirement dans la même unité) :

$$\text{Échelle } E = \frac{\text{Dimension sur le plan } (d_{\text{plan}})}{\text{Dimension réelle } (D_{\text{réelle}})}$$

2. Échelle de réduction ($1/N$)

Une échelle de réduction s'écrit sous forme d'une fraction $1/N$ (exemples : $1/20^e$, $1/50^e$, $1/100^e$), où $1\text{ cm}$ sur le dessin représente $N\text{ cm}$ dans la réalité :

  • Pour calculer la dimension réelle : $D_{\text{réelle}} = d_{\text{plan}} \times N$
  • Pour calculer la dimension sur le plan : $d_{\text{plan}} = \frac{D_{\text{réelle}}}{N}$

3. Règle méthodologique indispensable

Avant tout calcul ou comparaison, toujours convertir toutes les mesures dans la même unité (généralement en centimètres pour les plans d'architecture de salon).

Rappels : $1\text{ m} = 100\text{ cm} = 1000\text{ mm}$ • Pour passer de $\text{m}$ à $\text{cm}$, on multiplie par $100$.
